File references in this notice are relative to the source/ directory (or its extracted source archive). The deployed index.html also embeds the adapted model and rigging data.

The anatomical geometry in this version is adapted from Z-Anatomy, using bones, cartilage and selected major muscles in one original coordinate frame. It replaces the mixed OpenSim/procedural model used by earlier versions.

Changes made for this app (2026-10-01):
- Selected 313 bone/cartilage structures and 116 major muscle structures; excluded internal organs, nervous system and inner-ear assets with separate noncommercial credits.
- Extracted the original object transforms; uniformly changed axes from Blender X-left/Z-up/−Y-forward to X-left/Y-up/Z-forward. No per-bone rescaling or independent centering.
- Reduced polygon counts while preserving original tendon/cartilage material boundaries, then packed the surfaces for offline use.
- Derived hip and shoulder pivot positions from source articular surfaces and other joint references from the published skeletal rig.
- Added an original simplified 21-joint viewer rig, smooth skin weights, illustrative gait, user angle offsets, and ground-reference alignment. These are not a validated biomechanical simulation.
- Added high-detail WebGL rendering and a clearly labelled lower-detail Canvas 2D compatibility representation.

The source project also credits the University of Dundee / CAHID for “Cranial Nerves and Foramina” (CC BY 4.0). The full source README is retained in model-assets/SOURCE-README.md; noncommercial inner-ear/kidney assets and nervous-system models were not selected.
