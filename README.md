# StrideLab · 步态工坊

交互式三维跑步肌骨教学模型，主版本 2.6.4。
本人主要研究跑步生物力学与跑姿分析，临床实践中总是难以直观让客户了解自己的姿态状态与改正动作，该项目可直观调整姿态便于客户理解

## 使用

仓库、网页、模型及源码现已公开。网页使用 GitHub Pages 免费托管；也可下载后直接打开 `index.html`。模型、脚本、样式和参考曲线均已内置。

- 拖动旋转，滚轮缩放，右键平移
- 空格播放／暂停，R 复位
- 在矢状面、冠状面、横断面调整姿态；界面中的 `?` 提供完整操作与模型说明
- 不支持 WebGL 的浏览器会使用低细节 Canvas 兼容绘制；实际表现取决于设备和浏览器

## 模型范围

这是带接触约束的姿态探索与教学工具。下肢参考来自 RBDS003 一位参与者的公开跑步数据，上肢与部分空间联动为示意。它不是个体诊断、运动处方、肌力／关节负荷预测或经验证的动力学仿真。
